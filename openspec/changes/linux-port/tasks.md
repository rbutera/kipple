# Tasks

Waves for the /wave skill. Each wave ends with `make check` green on macOS and `make test-linux` green in the Linux container (from task 1.1 on), and is committed before its review gate. Every filesystem test runs against a `testutil.NewHome` fixture with `KIPPLE_HOME` and `KIPPLE_STATE_DIR` set; nothing ever touches the real home of the Mac, the colima VM, the container user or a CI runner. Test names follow the spec scenarios (`specs/<capability>/spec.md`).
